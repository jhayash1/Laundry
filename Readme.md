# Laundry Wallah / Laundry Mart

A simple HTML website for **Laundry Wallah / Laundry Mart**. The webpage introduces the laundry service, displays available services and pricing, and allows users to book a service through a basic form.

## Features

- Welcome Header
- About Section
- Laundry Image
- Services List
- Price List Table
- Book Now Form
- Footer with Contact Information

## Technologies Used

- HTML5

## Project Structure

```
LaundryWallah/
│── index.html
│── README.md
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` or open it in any web browser.
